# Velox

Multi-carrier shipping platform for the US and Canada: compare rates, buy labels, track parcels.
English, French and Spanish.

**Status:** Phase 0 (architecture). No application code yet. See [PROGRESS.md](PROGRESS.md).

- Architecture & specs: [`docs/`](docs/README.md)
- Stack: Angular + Bootstrap 5 · FastAPI + SQLAlchemy 2 · PostgreSQL · EasyPost · Stripe
- Native development and deployment (no Docker).
